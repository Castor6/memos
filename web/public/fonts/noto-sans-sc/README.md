# PDF 中文字体

PDF 导出时按需读取本站字体，不依赖第三方字体服务；日常浏览不加载。

字体来自 [Noto Sans CJK Sans2.004](https://github.com/notofonts/noto-cjk/tree/Sans2.004/Sans/SubsetOTF/SC)，采用随附的 SIL Open Font License 1.1。原文件未修改，仅简化本地文件名；覆盖简体中文地区子集，包含常用繁体中文和拉丁字符，不保证覆盖全部语言或 Emoji。
