# 笔记与待办编辑器

正文使用 Tiptap / ProseMirror 所见即所得编辑，`EditorController` 仍以 Markdown 与既有保存接口交互。状态与保存逻辑沿用 `state/`、`services/`、`hooks/`；外部工具栏通过控制器操作编辑器；编辑器内部的选区浮动工具栏直接复用 Tiptap 命令。

## 内容与兼容

- `Editor/index.tsx` 装配段落、标题、列表、任务列表、代码、表格、高亮、下划线、折叠、媒体与兼容内容扩展。编辑时不展示格式标记；序列化会规范化 Markdown 的空白及列表编号。下划线保存为 `<u>`，加载后仍可直接编辑。
- `Editor/editable-details.ts` 支持独立 `<details><summary>` 的标题和正文编辑、多行 Markdown 及可无损转换的 HTML。编辑时展开，阅读时默认收起；标题 Enter/Shift+Enter 进入正文，正文末尾 ArrowDown 退出折叠继续输入，保存快捷键沿用账号偏好。
- 插入菜单创建折叠，选区浮动菜单可显式转换完整折叠语法；不完整或不支持的输入保留原文字并提示。列表、引用或已有折叠中插入时，新折叠置于最外层当前块之后，保留原内容归属及待办状态；折叠正文内部支持待办列表。
- `Editor/preserved-content.tsx` 对无法安全转换的历史 HTML、嵌套／容器内折叠、公式及脚注采用保留原文的内容块并安全渲染预览。这些块可整体移动/删除，周围可继续编辑，暂不提供其内部的富文本编辑，避免未知内容经过转换丢失。
- `Editor/media.ts` 在光标位置显示媒体或文件卡片；`lib/inline-media.ts` 统一 Markdown 编码。图片语法的 title 以 `memos:file:<mime>` 或 `memos:reference` 标明类型，链接仍指向原附件/笔记。
- 历史底部附件在展示时按原顺序补到正文末尾；进入编辑后转为正文块。删除块后保存会移除对应附件关联，沿用服务端的附件清理规则。
- 笔记引用保存插入时的摘要，并链接到原笔记；摘要不是实时同步镜像。仅允许同空间的笔记相互引用，待办不参与引用。
- 旧 CodeMirror 辅助文件暂保留供已有纯函数测试使用，运行时入口不再加载旧编辑器。

## 标签与待办

标签由 `components/EditorTags.tsx` 固定在编辑框上方管理，保存在 memo payload，正文输入 `#` 不触发标签操作。旧笔记提取出的标签在首次编辑时保留，原文不进行破坏性替换；之后正文变化不再重算独立标签。

旧笔记的查看视图会在 Markdown 解析后隐藏与顶部标签区重复的标签节点，不改写源数据；代码、链接和转义的 `#` 保留。启用独立标签的新笔记不做这种隐藏，正文中的 `#文字` 是普通文本。

待办使用相同正文编辑基础，`isTodo` 区分持久化类型和列表查询。新建时从一个空复选框开始；卡片按 Markdown AST 统计实际事项，代码中的复选框文本不计入完成进度。不增加标题、截止时间或提醒字段。

## 键盘、上传与草稿

- 默认 Enter 换行、Ctrl/Cmd + Enter 保存；账号偏好可切换为桌面 Enter 保存、Ctrl/Cmd/Shift + Enter 换行。
- 触摸设备 Enter 始终换行，点击保存按钮提交；输入法组合期间不提交。列表换行续接，空项换行退出。
- 文件粘贴、拖入、选择均在正文插入占位并立即上传；上传完成前不可保存。失败后可重试或移除。成功后替换为服务端地址。
- 草稿按账号、编辑入口与空间隔离；缓存正文、独立标签、已上传附件和引用。上传未完成时保留此前可恢复的草稿，不缓存失效的 blob 地址。

## 空间与设置

空间定义、Enter 偏好、常用词与预览字数保存在服务端账号设置；标签 Emoji 等元数据按空间分开。当前选中的空间仅属于当前标签页，切换时完整导航以丢弃旧空间查询及进行中的响应。

API 通过 `X-Memos-Space` 传递空间，Store 上下文强制约束笔记和附件查询；无该头时属于默认个人空间。后台任务用无范围上下文处理全部数据。空间和内容类型创建后不可通过修改笔记接口改变。

空间归属与待办类型分别存入 `memo.space`、`memo.is_todo` 和 `attachment.space`，作为唯一数据来源。0.30.2 迁移回填旧 JSON 并移除旧属性；缺少空间的历史数据归入默认个人空间。列表、附件与引用索引随三驱动迁移创建，详见 `docs/personal-content-storage.md`。

## 交互约定

- 底部依次为常用词、段落、列表、文字、插入、更多，常用词独立置于最前。可用宽度小于 560px 时分成工具和保存两行，不横向滚动；可见范围和保存/取消始终可见。
- 选区浮动菜单提供加粗、斜体、下划线、高亮、链接和更多文字操作；与底部菜单复用 `Editor/rich-formatting.ts` 的命令及状态。清除文字格式保留链接、标题、列表与待办结构。菜单取消时消费选区书签，链接弹窗保留原选区，保存中忽略迟到编辑命令。
- 标签添加菜单关闭后，向前 Tab 直接进入正文文字位置；保留复选框键盘访问和列表内部 Tab/Shift+Tab 缩进。
- 不自动在列表后补空段落；进入编辑时定位正文末尾，工具栏操作后仍回到原选区。
- 标签筛选自动带入新草稿，取消或切换筛选仅撤回自动带入项；手动标签和已有笔记不受影响。列表加载筛选结果时保持编辑器挂载，避免丢失选区和标签来源。
- 引用导航使用历史返回；Esc 返回上一层引用来源，编辑器、菜单和弹窗打开时优先处理当前操作。
- 侧栏统计按持久化 `is_todo` 类型筛选，不按是否包含 Markdown 勾选框推断。捷径的 `is_todo` 保存在原有用户设置 JSON 中；历史捷径默认属于笔记，两类分别管理。
