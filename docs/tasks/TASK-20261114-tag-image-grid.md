# TASK-20261114-tag-image-grid：标签“图片底部网格”风格与复制内容不隔行

- 记录日期：2026-11-14（事实截至本次工作，不表示实时进度）
- 模块与关键词：TagMetadata、image_grid、MemoBody、MemoImageGrid、MemoEditor 附件、复制内容、memoCopyText
- 维护归属：分支 `feat/tag-image-grid`
- 代码基线：`d777e64b6`

## 背景与目标

- 给标签增加一种可切换的显示风格：带这种标签的笔记，粘贴或上传的图片不插入正文，而是在正文底部以网格展示。主要是为了在手机上整体浏览更有感觉。
- 右键菜单「复制 → 复制内容」有两个问题：
  - 每行之间都多一行空行。编辑器每按一次回车就新起一个段落，Markdown 存成 `a\n\nb`，而复制时原样写入剪贴板。
  - 网格风格的笔记，复制内容不应包含图片。

## 验收标准

- [x] 标签右键菜单和“管理标签规则”都能开关“图片底部网格”，并按用户、按空间保存。
- [x] 网格风格笔记的图片，包括已经内联在正文里的旧图片，都在正文下方按方格展示：手机固定 3 列，电脑按卡片宽度铺满，每列宽度接近手机。
- [x] 一两张图也用方格展示。点击后以图集方式预览，可以左右切换。
- [x] 网格风格下，编辑器中新粘贴或上传的图片不插入正文，进入底部图片区，可以移除，保存后不丢失。
- [x] 所有笔记“复制内容”时不再隔行；刻意留出的空行保留；网格风格笔记复制时不含图片。

## 讨论结论

- 2026-11-14 用户确认的内容：
  - “不要自动换行”指的是复制后每行之间多出的空行，不是要求去掉 Markdown 标记。
  - 电脑端按用户的想法设计：手机固定 3 列，电脑按每张卡片的横向宽度铺满，每列宽度与手机接近。
  - 只有一两张图时也始终用方格，保持浏览节奏一致。
  - 旧的内联图片在网格风格下也移到底部。只改显示，不改写正文，把风格切回去即可恢复。
- 开关保存在已有的 `UserSetting.TagsSetting.TagMetadata` 中，链路照搬 `blur_content`。设置以 JSON 存在 `user_setting` 表里，不需要数据库迁移。
- 原有保存逻辑会丢掉正文中没有引用的附件，这和“图片不在正文”冲突。因此改为同时保留正文引用的附件和编辑器底部图片区中的附件。
- 本环境没有 ImageGen，按 AGENTS.md 先说明方案再直接实现，实现后交付实际运行截图。

- 2026-11-15 实现中补充：服务端按请求顺序保存附件（`store/memo_mutation.go` 按序写入 `updated_ts`），所以保存时按底部网格的顺序提交附件；编辑器内同时上传的多张图片也按选择顺序排列，不按上传完成先后排列。

## 实现结果

- 后端与 Proto：`TagMetadata` / `UserTagMetadata` 新增 `image_grid = 4`，双向转换补上该字段，并扩展了 `TestUserTagSettings`。只重新生成了相关的 Go、OpenAPI、TS 输出；远程插件版本漂移导致的其他生成文件改动已还原。
- 标签设置：
  - `TagSettingsMenu` 的右键菜单新增“图片底部网格”勾选项，写入该标签的精确规则，并继承当前匹配规则的其他字段。
  - `Settings/TagsSection` 新增开关；新增规则行和已配置规则行的控件改为可换行，避免挤压。
- 阅读视图：
  - `lib/memo-image-grid.ts` 的 `splitMemoImages` 用 mdast 剪出正文中链接以外的图片（`memos:file:image/*` 和普通图片）。只剩图片的顶层段落连同其后的空行一起移除，再追加正文中没有引用的图片附件。
  - `MemoBody` 在网格风格下渲染剩余正文，并在 `ClampedSection` 之外渲染 `MemoImageGrid`。网格位于模糊和私密遮罩之内。
  - 方格使用缩略图，点击后以图集方式预览。
  - 网格样式：`grid-cols-3`，`sm` 以上为 `repeat(auto-fill,minmax(7.5rem,1fr))`。
- 编辑器：
  - 编辑器状态新增 `metadata.gridAttachments`，草稿缓存同步保存。
  - 网格风格下，新图片不插入正文，上传后进入编辑器底部网格，可移除；上传中显示加载占位。
  - `fromMemo({ detachImages })` 不再把未引用的图片附件追加进正文。
  - 保存时保留正文引用的附件和 `gridAttachments` 中的附件，删除正文内联图片仍会去掉对应附件。
- 复制内容：
  - `lib/memo-copy.ts` 的 `memoCopyText` 用一个换行连接块与块，`&nbsp;` 空段落保留为一行空行，硬换行改为换行，代码之外解码 `&amp;` 等实体。
  - 网格风格时移除图片。
  - 复制失败时提示错误。
