- 维护归属：分支 `feat/tag-image-grid-inherit`

- 前序任务：`docs/tasks/TASK-20261114-tag-image-grid.md`

## 背景与目标

- “图片底部网格”改名为“图片网格”。
- 标签菜单中这一项原先用分隔线隔开，左侧没有图标，开启时左侧显示对勾，和“重命名”“设置图标”不统一，需要重新设计开启状态。
- 新需求：父标签设置图片网格后，下面所有子标签统一跟随；之后允许子标签单独调整。

## 验收标准

- [x] 菜单、设置和说明文案统一为“图片网格”。
- [x] 菜单项不再用分隔线隔开，左侧是网格图标，右侧小开关表示状态，点击后菜单不关闭。
- [x] 子标签没有单独设置时跟随最近一个有设置的祖先，以后新建的子标签也跟随；跟随时显示“跟随 父标签”。
- [x] 在父标签上切换时，清掉所有子标签之前的单独设置。
- [x] 子标签可以单独开或关；切回与父标签相同的状态时自动恢复跟随。

## 讨论结论

- 2026-11-16 用户选择的方案：
  - 继承规则：父标签切换时统一覆盖，清掉子标签之前的单独设置，之后再单独调整子标签。
  - 开启状态：右侧小开关；跟随父标签时在文字下方显示灰色小字。
- 原先的 `bool image_grid` 无法区分“未设置（跟随）”和“明确关闭”，因此改为 `optional bool`，字段号不变。旧数据中的 `false` 没有被 protojson 写入，读出来为“未设置”；`true` 仍为明确开启，不需要迁移。
- 继承只作用于图片网格；Emoji、颜色和模糊不变，仍是匹配到的第一条规则生效。
- 本环境没有 ImageGen，按 AGENTS.md 说明方案后直接实现，交付实际运行截图。

## 实现结果

- Proto 与后端：`UserTagMetadata` / `UserSetting.TagMetadata` 的 `image_grid` 改为 `optional bool`。只保留相关的 Go、OpenAPI、TS 生成文件，插件版本漂移带来的其他改动已还原。转换函数直接传递指针，保留字段存在性；`TestUserTagSettings` 增加断言：明确的 `false` 保留，未设置读回为 nil。
- `lib/tag.ts`：
  - `findTagMetadata` 改为泛型，设置对话框的本地草稿也能使用。
  - `resolveTagImageGrid` 依次查找标签本身和各级父标签。每一级沿用精确规则优先、其次正则的匹配，遇到第一个有明确值的规则就采用，并返回继承来源 `source`。
  - `hasImageGridTag` 改用继承解析，阅读视图、编辑器和复制内容自动支持继承。
  - `applyImageGridToggle` 只保存与父级不同的值，同时清掉 `${tag}/` 下所有子规则的值。可选 `isEmpty` 会删除清空后没有任何字段的精确规则；如果删除后会有正则规则接管该标签，就保留这条规则。
- 菜单：新增 `DropdownMenuSwitchItem`，基于 Base UI 的 CheckboxItem，保留 `menuitemcheckbox` 语义，右侧开关只用于展示。`TagSettingsMenu` 去掉分隔线，切换时删除空规则。
- 设置对话框：规则行的开关显示有效值，继承时显示“跟随 X”。切换时同样清掉子规则行的值，但不删除规则行。新增规则时，关闭状态保存为“未设置”。指定标签打开对话框时，不再把匹配规则的网格值固化下来。

- 2026-11-16 用户验证时发现：打开“管理标签规则”时，标签名输入框的下拉建议会自动弹出。原因是 `TagSettingsDialog` 使用 `initialFocus`，焦点落到第一个可聚焦元素，也就是带 `datalist` 的输入框，浏览器聚焦时会显示建议列表。这个问题从 #18 起就存在，不是本次引入的。修复方式：`initialFocus` 改为对话框自身的 ref，打开时焦点在对话框上，按 Tab 进入输入框，Esc 仍可关闭。
- 2026-11-16 用户又发现：关闭“管理标签规则”时，会闪一下只有标题的弹窗。原因是内容按 `{open && <TagsSection />}` 渲染，`open` 一变成 false 内容就卸载了，但弹窗的关闭动画还在播放。修复方式：去掉 `open &&`，让内容在关闭动画期间保持渲染。Base UI 会在动画结束后卸载整个弹层（未使用 `keepMounted`），所以每次重新打开时草稿仍会重置。

## 未覆盖范围与后续建议

- 统一覆盖只清除名称以 `父标签/` 开头的精确规则；如果正则规则直接匹配子标签并设置了网格，它仍然生效。
- 模糊、颜色、Emoji 没有父子继承；如有需要，可以复用 `resolveTagImageGrid` 的逐级查找方式。
