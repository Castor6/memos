## 已确认的需求与设计

用户先要求对齐需求，查看静态效果图和三点动效演示后，于 2026-10-21 明确授权一并实现以下调整：

- 列表卡片字数从时间旁移至右侧操作区最前方，位于表情、待办进度和更多按钮之前；笔记与待办保持一致。共用卡片头的详情与分享页同步右置，编辑器字数位置不变。
- 打开应用时尽早显示启动过渡，资源加载和应用初始化之间不重新露出空白；实际路由界面可显示后退出，不为展示动画人为延迟。
- 选定 B 方案：浅底、叠放白纸、现有黑白鹦鹉图标、Memos 名称和简短加载文案；纸页轻微浮动，三个绿点从左到右轻轻上浮、变亮并落回。用户曾比较转圈方案，最终明确选择三点起伏。
- 兼顾深色模式和系统减少动态效果偏好；等待过长时提供重试反馈。初始 HTML 尚未到达或操作系统启动窗口的阶段，不属于页面内动画能保证覆盖的范围。
- 一个筛选条件时隐藏整体“清空”，保留条件自身的移除按钮；两个及以上才显示整体“清空”。按实际筛选条件计数，“任一／全部”不是额外条件。
- 笔记与待办侧栏预留稳定的滚动条空间，使搜索框与日历不因标签数量及是否滚动而改变宽度；不通过调整字号补偿。
