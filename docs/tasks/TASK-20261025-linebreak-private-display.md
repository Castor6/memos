- 记录日期：2026-10-25

- 维护归属：本会话，分支 `design/private-display-preview`
- 关联任务：[私密能力](TASK-20261017-clipper-privacy-pin.md)、[私密筛选入口](TASK-20261020-memo-todo-count-filters.md)

## 背景与目标

用户先要求对齐两项需求并提供设计预览，随后确认方案并授权实施。

1. 编辑框中的换行保存后仍应显示。
2. 私密内容默认隐藏，点击某条后显示；在现有“私密”按钮旁增加统一控制显示与隐藏的开关。

## 已确认需求

- 手动换行、正文中间的空行、连续多个空行以及正文首尾空行都原样保留，与编辑框一致。
- 私密内容直接模糊遮挡，中央不显示“点击查看”或其他提示文字。
- 刷新页面或下次进入时重新隐藏，不持久保存“全部显示”的状态。
- 用户认可眼睛图标控制显隐的方向，要求使用标准图标库中的眼睛，并让它与“私密”的关联更加明显。
- 用户认可第三版分段胶囊外观，要求眼睛不带斜杠；当前图标确定为标准 `Eye`，不再采用 `EyeOff`。
- 2026-10-25：用户明确“可以，那开始实现吧”，按已确认方案实施。

## 确认方案

- “私密”沿用现有 `mcp_hidden` 语义。“私密筛选”和无斜杠眼睛共用分段胶囊外框、以细竖线分隔，左右独立点击；分组外观和无斜杠眼睛已获用户认可。
- 开关默认关闭；开启时统一显示私密内容，关闭时统一隐藏，包括此前单独展开的内容。
- 关闭状态下点击某条模糊内容，仅临时显示该条。
- 保留卡片尺寸、头部私密标记、时间、字数和操作菜单；正文及其图片、附件预览等内容一起遮挡，普通笔记保持清晰。
- 桌面控件位于原侧栏；手机控件位于原筛选抽屉中，不新增常驻侧栏。
- 开关只控制软件内呈现，不修改笔记的私密属性、MCP 屏蔽或分享权限。
- 实施范围覆盖列表、详情及相关内容预览；只控制应用内阅读，分享链接和导出沿用原权限与展示规则。空段保存为既有 Markdown 渲染链支持的实体，不修改导出或扩展模块。

- 新增会话内私密显隐状态、可键盘操作的模糊遮罩和私密/眼睛分段按钮；刷新或切换账户重置，统一隐藏清除单条揭示。
