## 背景与目标

单标签右键菜单错误地定位在三个点下方；用户只需要重命名和设置图标。平铺卡片、编辑器的图片过大。

## 验收标准

- [x] 右键菜单出现在鼠标位置，三个点仍按按钮定位；仅有重命名和设置图标。
- [x] 重命名更新当前空间自己的笔记和待办（含归档），同步子标签、图标和当前筛选；错误可见并可重试。
- [x] 图标提供多组常用选项，可自定义、恢复默认，保存后刷新保留。
- [x] 编辑器、正文图片及附件画廊限制预览尺寸，保持比例，手机不横向溢出。
- [x] 完成前端检查及桌面、手机尺寸浏览器验收。

## 实现结果

- 单标签菜单仅有重命名和设置图标，右键使用鼠标虚拟锚点，按钮使用原触发器锚点，并保留边界避让。
- 独立图标弹窗提供 5 组共 72 个常用 Emoji、自定义输入和恢复默认；保存保留其他标签规则及既有颜色、模糊属性。
- 重命名先分页收集当前空间自己的普通笔记、待办和归档，再读取最新标签逐项更新，保持正文不变；处理子标签、重复标签、长度校验、同名冲突和自子树校验。同步样式元数据及当前标签筛选。
- 重命名使用现有 API，非跨笔记事务；网络中断可能部分完成，错误提示说明已完成部分保留。重试匹配仍使用旧标签的笔记。
- 编辑器和正文图片上限宽 480px、高 320px，保持比例和容器内缩放；附件画廊宽度上限 480px，原图预览逻辑不变。
- 新增 patch Changeset，无后端、数据库或依赖变更。
