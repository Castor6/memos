## 背景与目标

修复用户反馈的八项交互问题。截图文字仅作为界面示例，不增加额外需求。在最新 main（8c30398f）创建 fix/editor-and-todo-experience 分支。

## 验收标准

- [x] 编辑器任务勾选框与正文第一行垂直居中，长文字续行不影响对齐。
- [x] 热力图和标签按笔记 / 待办分别统计；捷径分开保存和管理，旧捷径归入笔记。
- [x] 取消标签筛选时移除自动带入的标签，保留手动添加的标签和正在编辑的已有笔记标签。
- [x] 编辑器与卡片适配可用屏幕宽度，支持平铺且手机无水平溢出。
- [x] 从引用进入笔记后 Esc 返回来源，编辑或弹窗中 Esc 不误跳转。
- [x] 编辑工具整合为一行；常用词用图标入口，保留可访问名称。
- [x] 选中文字显示格式工具栏，应用格式保持选区。
- [x] 编辑已有待办时光标定位正文末尾，不自动落入额外空行。
- [x] 前端 lint、单元测试、生产构建及相关后端检查通过。
- [x] 内置浏览器验证 1440×900、430×739、430×932，恢复视口覆盖。

## 实现结果

- 任务列表复选框按第一行行高居中，长段落保持正文列内换行。关闭 Tiptap 自动补末尾段落；初始化编辑时显式 focus("end")。
- 插入、格式、常用词等操作合为单行，工具区域窄屏横向滚动；常用词为图标入口。Tiptap BubbleMenu 提供选区加粗、斜体、删除线、行内代码、高亮。
- 标签记录自动来源，筛选变化撤回自动标签；已有标签和手动标签不受影响。等待草稿初始化后再同步，筛选请求加载时保持编辑器挂载。
- 列表去掉固定最大阅读宽度，多列去掉 420px 列宽上限，沿用列表 / 2 列 / 3 列 / 自动选项铺满可用空间。
- 引用卡片、引用列表和详情关系图带入引用导航标记，详情页 Esc 历史返回；编辑器、菜单、对话框打开时不误跳转。
- CEL 新增已有数据库列 is_todo 的布尔筛选；侧栏使用后端全量统计并限定内容类型及作者，沿用原权限和空间约束。待办搜索提示和日历计数名称同步区分。
- Shortcut API 及原用户设置 JSON 新增兼容的 is_todo 字段，无数据库结构变更。旧捷径默认为笔记；管理页按类型切换，侧栏新建/编辑保留所属类型，列表只应用当前类型的捷径。
- 通过 buf generate 生成 Go、TypeScript 和 OpenAPI，撤回无关生成器版本产生的文件变动。中文 minor Changeset：thin-zoos-crash.md。
