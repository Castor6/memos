## 背景与目标

基于 main `0369d535`，对齐 MCP 中 memos 标签的四项未完成需求。服务器生成 PDF，点击导出显示进度并自动下载，不再显示预览弹窗；浏览器不再下载字体。链接标题和摘要抓取后持久保存，刷新和重启复用历史结果。

## 验收标准

- [x] flomo 侧栏平铺和树状标签恢复简洁无配色样式；正文及富文本编辑链接均为蓝色。
- [x] 编辑历史笔记点击添加标签不跳顶，候选键盘操作正常。
- [x] 链接元数据后台抓取后持久保存，读取笔记即获得已缓存预览，失败可重试。
- [x] PDF 在服务器生成，中文可复制，包含图片、表格和完整长文；直接下载、显示进度及失败提示。
- [x] 完成可运行的自动检查与桌面、两种手机高度验证；容器边界见下。

## 讨论结论

- 单用户场景，PDF 使用基本超时及防重复点击即可；用户确认引入 Node 排版组件并调整运行镜像，复用 pdfmake 和 Noto Sans SC 字体。
- 标签跳顶发生在点击添加标签时，尚未选择候选。
- 链接缓存成功后不自动刷新历史标题、摘要；首次未完成可显示占位。

## 实现结果

2026-09-21：

- flomo 侧栏使用独立的标签标记，平铺和树状列表均保持灰色文字、透明背景；富文本链接补齐主题蓝色规则。
- 标签弹窗改用 preventScroll 聚焦；候选定位只修改列表 scrollTop，不再调用会滚动祖先的 scrollIntoView。
- 新增 SQLite、MySQL、PostgreSQL 的 link_metadata 表及增量迁移。按 URL 的 SHA-256 定位，首次成功快照写入后不覆盖，不设置自动失效。
- 后台按分钟分批扫描独立链接，补抓历史笔记，成功缓存跳过，失败后续重试；沿用外链网络限制，支持关闭时取消请求。不在后台改写笔记正文或更新时间。
- 元数据接口先读持久缓存；Memo 新增只读 link_metadata 字段，卡片优先直接展示随笔记返回的快照。首次尚无快照时保留加载状态和失败回退。
- PDF 增加普通及分享导出接口，复用现有可见性和分享授权；Go 读取完整正文与有权限的图片，再调用独立 Node 排版进程。分享授权不扩展到其他笔记附件。
- 将 Noto Sans SC 字体和 pdfmake 移到 scripts/pdf；浏览器移除字体和排版依赖、预览弹窗，改为生成状态、自动下载和失败重试，防止重复点击。
- Node 22 Alpine 运行镜像包含锁定依赖及字体，保留 amd64/arm64/arm/v7 目标；本地 setup 与 CI 补充组件安装和测试，镜像新安装/升级冒烟实际请求 PDF。
- 使用 Changesets CLI 生成中文 minor 发布说明，并补入服务端 PDF 的用户可见变化。
