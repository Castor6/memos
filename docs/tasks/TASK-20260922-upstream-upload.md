## 验收标准

- [ ] 上传使用 2 MiB 分块、30 分钟空闲过期；绑定用户与起始个人空间，重启后明确失效。

- [ ] 网页按块读取文件并支持短时重试，保留原有即时上传流程与动态照片元数据。
