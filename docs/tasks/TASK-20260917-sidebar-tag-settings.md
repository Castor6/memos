## 背景与目标

用户希望在侧栏通过标签右键及行末三个点配置标签，不再从设置页进入。

## 验收标准

- [x] 平铺及树状标签支持右键和行末三个点，打开标签设置，不误触筛选。
- [x] 可编辑 Emoji、颜色和内容模糊，保存后刷新仍保留，取消不保存。
- [x] 设置页移除标签入口，侧栏保留管理全部规则的入口，已有正则规则可维护。
- [x] 验证桌面与 430px 手机布局，无移动端常驻左栏。

## 实现结果

- 平铺及树状标签通过共享菜单组件提供右键和行末三个点；普通点击继续筛选。
- 复用现有标签设置表单，单标签打开即编辑，无需先添加规则；继承匹配规则的默认值，保存时保留其他规则。
- 设置页移除标签入口；侧栏标题菜单提供全部规则管理，空标签列表也可使用。
- 保存失败提示错误并保留输入，保存中禁止重复提交；移除规则按钮注明不会删除标签或笔记。
- 新增 patch Changeset。
