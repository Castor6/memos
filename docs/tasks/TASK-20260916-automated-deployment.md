## 背景与目标

用户要求解释发布与部署的区别，通过浏览器配置并走通自动部署流程；明确选择免费 ACR 个人版。延续既有方案，由 GitHub 构建发布镜像，服务器主动拉取更新。

## 验收标准

- [x] 在免费 ACR 个人版创建私有仓库，不购买付费实例。
- [ ] 仅合并版本 PR 才发布确定提交对应的版本镜像，普通合并不部署。
- [ ] GitHub 只保存镜像发布凭据，不保存服务器 SSH 私钥；实际服务器地址和运维秘密留在私有维护目录。
- [ ] 镜像按摘要固定；拉取失败时旧服务持续运行；更新任务串行执行。
- [ ] 更新前停止应用并备份完整数据与配置，验证备份后更新；验证失败有明确恢复路径。
- [ ] 在一次真实更新中核对版本、登录、笔记与附件访问，并启用定时更新。
- [ ] 更新公开部署说明和私有维护记录，明确已实现、已验证与仍未验证的范围。
