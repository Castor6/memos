## 背景与目标

用户反馈点击编辑器任务列表按钮后，光标及输入文字出现在复选框下一行。已按要求切到 main 并拉取至 `59c6b394`，在 `fix/task-list-cursor` 分支修复。

## 验收标准

- [x] 新建空任务项时，光标与输入文字位于复选框右侧。
- [x] 换行续接任务项、勾选、长文本换行及保存后重新编辑正常。
- [x] 桌面 1440×900、手机 430×739 / 430×932 布局正常，手机无常驻左侧栏。
- [x] 前端 lint、单元测试、生产构建和差异空白检查通过。

## 实现结果

Tiptap 的任务项实时 NodeView 输出 `li[data-checked]`，没有静态序列化输出中的 `data-type="taskItem"`。旧样式未匹配，导致正文块落在复选框下一行。改用任务列表直属 `li` 匹配布局，复选框标签固定不收缩，正文保留弹性宽度及长文本换行。
