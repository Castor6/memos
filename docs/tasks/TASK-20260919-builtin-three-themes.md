## 背景与目标

将截图对应的三套试用 CSS 内置为个人主题选项，免去手动粘贴。薄荷花园不包含叶片及其它插画装饰。

## 验收标准

- [x] 偏好设置和紧凑主题选择器可选择三套新主题，中文界面显示中文名称。
- [x] 主题立即生效，可保存、刷新恢复，切换回原主题不残留新样式。
- [x] 薄荷花园无叶片；三套主题不改变原有功能与导航结构。
- [x] 完成前端 lint、测试、构建及桌面/430px 窄屏检查。

## 讨论结论

保留现有跟随系统、浅色、深色、纸张选项。flomo 简约只借鉴配色和组件质感，不复制其它软件的功能布局。已有系统自定义 CSS 仍由用户维护，试用旧 CSS 应清空以免覆盖内置主题。

## 实现结果

新增 cream、mint、flomo 三个主题文件，并接入主题验证、加载、本地缓存和浏览器 theme-color。设置、登录页紧凑选择器及用户快捷菜单共用主题清单，提供英文和简繁中文名称。

沿用原有个人设置 API，不修改认证或数据库。样式限定于对应主题，保留标签自定义颜色、评论卡片拼接和移动布局；薄荷花园不含背景图片。新增 minor Changeset。
