# TASK-20260919-mobile-export-experience：移动导航、导出与图片交互

- 记录日期：2026-09-19
- 模块与关键词：手机导航、Markdown、PDF、图片手势、Emoji、中文搜索
- 工作分支：`feat/mobile-navigation-note-export`

## 背景与目标

根据 Memos 标签下待办及逐项需求讨论，完善手机导航、单篇正文导出、图片手势和中文图标搜索。

## 验收标准

- [x] 手机顶部提供笔记、待办两个图标 Tab，其余入口保留左上角导航抽屉，保留筛选入口，无常驻左栏。
- [x] 单篇菜单可导出 Markdown 和 PDF；正文内文件保持顺序，MD 使用通用语法及完整地址，PDF 保留可选择文字并包含图片。
- [x] 图片支持双指缩放、放大后拖动及双击放大/还原，保留原按钮操作。
- [x] Emoji Mart 支持本地中文名称及关键词搜索，并保留英文、分类与最近使用。
- [x] 折叠文案改为“展开 / 收起”；字数及高度折叠逻辑保持不变。
- [x] 完成前端检查及桌面 1440×900、手机 430×739 / 430×932 验证，明确真机触摸验证边界。

## 讨论结论

- 不做设置自动保存、批量导出、正文外旧附件补齐，也不修改分享成图片功能。
- 导出以正文为准：图片保留在原位，视频和 PDF 等文件转为链接；不重复附加附件列表。
- PDF 优先采用浏览器打印排版与系统保存 PDF，保留文字和图片，不生成整页截图，不引入大型 PDF 运行库。
- 字数统计已排除普通图片地址；设置 0 在普通单列且未启用紧凑模式时不折叠，保留此行为。
- 中文关键词通过 Emoji Mart 支持的数据接口加入，使用 Unicode CLDR 数据。

## 实现结果

2026-09-19：完成以下实现。

- 复用导航数据提供手机顶部图标栏，保留用户菜单、通知未读数及筛选抽屉；桌面导航保持原布局。
- 笔记操作菜单新增单篇 MD / PDF 导出。通过 Markdown 语法树处理正文文件，保留原位置并生成完整链接，不补正文外附件。
- PDF 使用独立打印文档，嵌入正文图片，保留文字、表格、待办和代码；图片读取失败显示重试，准备完成后启用系统打印保存。
- 图片预览加入双指缩放、拖动边界、双击切换及切图重置，保留缩放按钮。
- Emoji Mart 加入 Unicode CLDR 中文名称及关键词，覆盖现有 1870 个基础图标，附来源与许可证，英文搜索保持可用。
- 简繁中文折叠文案更新为展开/收起，不改统计及阈值逻辑；添加 minor changeset。
