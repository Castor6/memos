## 背景与目标

用户确认将编辑框底部工具整理为常用词、段落、列表、文字、插入和更多，常用词独立置于最前。精简选区菜单，补齐下划线、可编辑折叠与旧语法转换，修复添加标签后 Tab 被默认待办复选框接住的问题。

## 验收标准

- [x] 工具分组及常用词顺序符合方案，窄于 560px 时分成工具和保存两行，无横向滚动。
- [x] 选区菜单与链接弹窗保持原选区，文字格式支持预设；清除样式保留链接及块结构。
- [x] 下划线保存、查看、刷新重新编辑均有效。
- [x] 可新建并编辑折叠标题和正文，完整语法可显式转换，历史单行、多行内容保持兼容。
- [x] 折叠前后继续输入，待办状态和进度保持；标签后的 Tab 进入正文，列表缩进不受影响。
- [x] 前端 lint、测试、构建通过；桌面及两个手机尺寸完成本地验收。

## 讨论结论

- 工具栏保留正文下方；新增下划线，不新增文字颜色或高亮调色板。
- 常用词独立入口置于最左；标签保持顶部，可见范围和保存始终可见。
- 折叠通过菜单创建或完整语法显式转换，编辑时展开，阅读时默认收起。
- 复用当前 Markdown 存储与安全渲染，未知内容保留原文，不更改后端 API 和数据库。

## 实现结果

- 2026-09-26：底部工具整理为常用词、段落、列表、文字、插入及更多。可用宽度小于 560px 时分成两行；430px 下常用词保留文字标签，其余入口精简为图标，菜单内显示名称。
- 新增共享富文本命令控制器，底栏和浮层使用相同的格式操作及状态。通过可映射选区书签保留弹窗目标，取消菜单立即消费书签，防止下一次操作误用旧选区。
- 下划线使用 `<u>` 保存并安全展示，重新加载仍可编辑；清除文字样式保留链接及块结构。编辑冻结期间拒绝迟到的格式和插入操作。
- 新增折叠标题和正文节点，兼容单行、多行及可安全转换的 HTML；特殊符号、实体、代码示例、空正文与异常内部编码均有回归覆盖。编辑标题后换行进入正文，正文末尾下方向键退出折叠，保存快捷键保持原偏好。
- 修复添加标签后向前 Tab 被待办复选框接住的问题。补充仅应用的 minor changeset，更新编辑器模块说明。

## 2026-09-26 追加需求与可行性评估

- 用户要求：列表里的折叠内容预览与编辑框统一；展开后的折叠区右下方提供收起入口；编辑框支持展开和收起，并提供相同的右下方收起入口；选中文字的浮动工具栏整体缩小，取消“更多”，直接展示操作图标，悬浮提示操作名称。
- 初次评估阶段仅检查可行性，未实施产品代码，也未运行功能测试；后续实施事实见下节。评估代码基线为 `a47855f0`。
- 源码依据：`MemoContent/MemoMarkdownRenderer.tsx` 未定制 details 渲染；`MemoEditor/Editor/editable-details.ts` 输出带 open 属性的折叠节点；`rich-editor.css` 已定义编辑框折叠边框、圆角及正文缩进。可统一两端外观，并分别接入阅读态和编辑态的展开状态。
- 选区工具栏 `SelectionToolbar.tsx` 复用 44px 的 `TOOL_TRIGGER`，删除线、行内代码、清除格式及条件显示的折叠语法转换位于“更多”菜单。可改为独立紧凑尺寸并直接展示；预计无需新增依赖或变更存储结构。
- 建议交互（尚未由用户确认）：列表沿用默认收起，新建折叠在编辑框默认展开；编辑框以独立箭头控制展开，标题文字用于编辑；展开时正文右下角显示“收起”，收起后仅在标题离开可视区域时将其带回视野。展开状态作为临时界面状态，不写入笔记。
- 建议桌面按钮缩至约 28–30px，图标约 14px；普通八项文字操作直接展示，可转换折叠语法时追加转换图标。窄屏容许换行，不恢复“更多”。需验证触摸命中范围和选区保留。
- 实施时需处理：编辑器收起时的光标安置、标题编辑与折叠点击分离、快捷键进入正文时展开、列表外层长文截断遮挡内部收起入口，以及历史保留内容的兼容性。验收应覆盖桌面、430px 两种高度、保存再编辑与长内容滚动；真实 iPhone 的选区和软键盘另行验收。

## 2026-09-26 追加交互实施结果

- 用户随后授权实施，并明确选区工具栏外框也同步缩小；实施中进一步要求删除线紧邻下划线，移除浮层中的行内代码和清除文字格式。此要求替代前节建议的八项操作，底部文字菜单保留原功能。
- 最终选区浮层顺序为加粗、斜体、下划线、删除线、高亮、链接；支持的完整折叠语法保留按条件显示的转换入口。按钮 28px、图标 14px、外框内边距 2px、圆角 6px，六项时整体 174×34px；悬浮和键盘聚焦使用现有 Tooltip 提示。
- 阅读与编辑共用 `Details/details.css`，统一边框、圆角、箭头、正文缩进和段落间距。阅读态 `DetailsBlock` 兼容富文本标题与嵌套折叠；原文保留块也复用该渲染。
- 编辑态 NodeView 将展开状态保存在视图，不产生 Markdown 修改或撤销历史；标题仍可直接编辑，独立箭头及右下角按钮控制收起。隐藏正文前将其中的选区移至标题，键盘进入隐藏正文时自动展开。
- 列表展开内层折叠时解除外层长文截断，避免底部收起入口被遮挡；收起时仅在标题被页面或编辑器滚动区遮住时滚回标题。
- 新增仅应用的 patch changeset `.changeset/honest-mirrors-say.md`，未改版本号。
